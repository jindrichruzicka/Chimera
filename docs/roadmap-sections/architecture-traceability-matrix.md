# Architecture Traceability Matrix

> Every feature maps to at least one architecture section. No feature exists without a `§` reference. If a feature lacks a `§` reference, it must not be planned.

What is measured here, and how strongly, is stated by `tools/traceability-matrix.test.ts`.

The census it differences against is the set of features that have a roadmap heading, so a feature without one reaches this table only if a row names it directly. F73 (Architecture Invariants Hardening) and F93–F96 shipped without ever gaining a roadmap section; the rows below name them directly, so the guard cannot see them and this sentence is what records that they are deliberate.
